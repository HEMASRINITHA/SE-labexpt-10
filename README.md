# Git Branching and Merge Conflict Resolution

## Aim
To demonstrate Git branching, collaboration, merging, and resolving merge conflicts using Git and GitHub.

## Introduction
Git is a distributed version control system used to track changes in source code. Branching allows developers to collaborate independently, while merging integrates changes from different branches.

## Objectives
- Create and manage Git branches.
- Modify and commit files.
- Push changes to GitHub.
- Merge changes from the main branch.
- Resolve merge conflicts manually.
- Create a pull request.
